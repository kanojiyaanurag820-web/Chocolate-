DARK GOLD CHOCOLATE WEBSITE
===========================

FILES
- index.html     Home page
- product.html   Product collection page
- login.html     Login demonstration page
- feedback.html  Customer feedback page
- style.css      Shared styling and responsive design
- script.js      Mobile menu and demo form interaction

HOW TO RUN
1. Extract this ZIP folder.
2. Open index.html in a web browser.
3. Use the navigation bar to move between all four pages.

NOTES
- Chocolate and portrait photos are loaded from Unsplash, so internet access is needed to display them.
- Add to Cart buttons are intentionally visual only.
- The login form is a front-end demonstration. It does not send or save the name, mobile number, or password.
- Customer comments are sample placeholder testimonials, not verified reviews.
- To make this a real shop, you would need secure server-side login, a database, and a checkout/payment system.
